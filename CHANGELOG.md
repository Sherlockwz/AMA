## [0.1.0] - 2026-08-22

### Added

- Initial public release of the AMA research implementation.
- OpenClaw memory plugin with automatic recall and capture hooks.
- Six explicit AMA memory tools and the `openclaw ama` CLI.
- Local FastAPI sidecar backed by SQLite and FAISS.
- Agent-facing `SKILL.md`, project page, setup guide, and reproduction guide.
- TypeScript and Python tests plus GitHub Actions validation.
